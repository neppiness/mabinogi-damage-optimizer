# 마비노기 데미지 최적화 도구
## 개요
* 마비노기 모바일에 데미지에 영향을 끼치는 항이 굉장히 많음
* 이에 대해서 어떤 주스탯/부스탯이 서로 어떻게 영향을 미치며 데미지를 증폭하는지 정리하고자 함
* 추가로 어떤 능력치를 획득하는 것이 더 데미지를 효율적으로 높일 수 있는지를 분석하는 툴로써 활용하고자 함

## 목표
1. 데미지 공식 구현
2. 현 상태에서 데미지 증분을 어떻게 가져가는 게 좋을지 판단할 수 있는 최적화 도구 구현
3. 프론트를 구현하여 각종 능력치를 손쉽게 입력 받을 수 있는 기능 구현

---

## 최종 대미지 공식

```text
대미지 = roundup(2 * rounddown(A * B, 0) * C * D * E * F * G * H * I * J * K * L * 스킬계수, 0)
```

### A. 공격력

```text
A = [캐릭터공격력] + [무기총합공격력] + [목걸이공격력] + [펫총합공격력] + [패션세트옵션] + [깡공인챈트] + [룬워드 깡공] + [팔라딘 환산공격력]
```

#### 캐릭터공격력 항

```text
[85레벨 기본공격력 + 레벨업카드 + 타이틀 보유효과
```

#### 무기총합공격력 항

```text
(무기 기본공격력 + 각인공격력 + 무기인장 + 숙련연계 추가공격력) * (1 + 엠블럼표기%) + 무기 주/부스탯 보너스대미지
```

#### 목걸이공격력 항
* 목걸이 공격력과 목걸이 인장 공격력의 합

#### 펫총합공격력 항
* 동행 능력치 "공격력" 스탯
* 펫의 힘/솜/지/의/행 능력치는 무기 스탯보너스에 포함

#### 패션세트옵션 항
* 패션 4세트 효과 "공격력" 스탯

#### 깡공인챈트 항
* 공격력을 절대값(+100, +120 등)으로 올려주는 인챈트 합

#### 룬워드 깡공 항
* 룬워드로 얻는 공격력 스탯

#### 팔라딘 환산공격력 항
* 정의(상시 깡공) + 심판(팔라딘 변신 시 깡공)


### B. 공증

```text
B = 1 + 템공증합% + 스킬공증합% + 공증인챈트%
```


### C. 피증

```text
C = [주피증배율] * [받피증배율]
```

#### 주피증배율 항

```text
(1 + 스위 / 8500) * (1 + 스킬피해%) + 헬리오% + 일부스킬피증% + 템주피증% + [시너지] 대미지증가%
```

* 버프형 시너지 스킬 (힐러, 사제, 수도, 음유 등)  
* 중첩 불가

#### 받피증배율 항

```text
1 + 방어구파괴% + [시너지] 받는대미지증가%
```

* 디버프형 시너지 스킬  
    - 예시: 산성유탄, 대검심찌 등  
    - 중첩 불가


### D. 강화류

```text
D = 1 + [연타강화배율] + [강타강화배율] + [광역강화배율] + [콤보강화배율] + [궁극기강화배율]
```

#### 연타강화배율 항
* 공식
```text
(1 + 연타강화 / 8500) * (1 + 연타피해%) - 1
```

* 연타 발생 시 적용

#### 강타강화배율 항

```text
(1 + 강타강화 / 8500) * (1 + 강타피해%) - 1
```

* 강타 발생 시 적용

#### 광역강화배율 항

```text
(1 + 광역강화 / 8500) * (1 + 광역피해%) - 1
```

* 멀티히트 발생 시 적용

#### 콤보강화배율 항

```text
[(1 + 콤보강화 / 17500) * (1 + 콤보피해%) - 1] * (n / 4)
```

* n 값

| 콤보 수 | n |
|---|---|
| 1콤~ | 1 |
| 10콤~ | 2 |
| 50콤~ | 3 |
| 100콤~ | 4 |

#### 궁극기강화배율 항

```text
궁극기 / 8750
```

* 궁극기 대미지에만 적용

#### 참고
* 궁극기 스탯은 궁게이지 회복량을 궁극기 / 7250 만큼 증가시킨다.


### E. 보석

```text
E = 1 + 보석태그댐증%
```

* 그린헬리오 포함


### F. 치명타
* 기대값 계산 시

```text
F = 1 + [치명타확률] * ([치명타배율] - 1)
```

* 실제 대미지 계산 시

```text
노크리: 1
크리티컬: [치명타배율]
```

#### 치명타확률

```text
MIN(0.5 - 1 / (2 + 치명타 / 1000) + 룬치확% + 캐릭크확증% + 치확보너스%, 100%)
```

#### 치명타배율

```text
(1.4 + 치명타 / 5000) * (1 + 치명타피해% + 캐릭크댐증%)
```


### G. 무방비

```text
G = (1 + 브레이크 / 5250) * (1 + 무방비피해%) + (무방비20% + [태그댐증합]) * (브익 시 2배)
```

* 태그댐증은 걸린 브레이크가 강화하는 태그에 맞춰 공격 시 발동

#### 브레이크별 태그 강화
* 블로우 : 강타 10% / 연타 10% / 화상 5% / 감전 5%
* 빙결 : 강타 10% / 연타 10% / 동상 5% / 감전 5%
* 매혹 : 강타 10% / 연타 10% / 정신 5% / 신성 5% / 암흑 5%
* 스턴 : 강타 10% / 연타 10% / 화상 5% / 동상 5%
* 멘탈 : 강타 10% / 연타 10% / 중독 5% / 출혈 5% / 정신 5%
* 석화 : 강타 10% / 연타 10% / 신성 5% / 암흑 5%


### H. 스킬계수강화 항
* 특정 스킬 대미지 증가 툴팁들의 합연산 혹은 곱연산

#### 특징
- 클래스별 테스트 필요
- 일부 스킬 대미지 증가 효과는 C항 피증이 아님
- 전격술사의 과충전 스택 딜증 / 파괴의섬광 딜증은 서로 곱연산으로 추정
- 명확한 기준 정립 어려움

#### 현재 확인된 합연산 관계
* "~스킬로 주는 피해% 증가" 툴팁을 가진 아이템 성능 수치

#### 예시
- 룬 갈퀴발톱 / 룬 대마법사 / 아티팩트 마력

#### 현재 기준 정리
```text
H ≒ (1 + "~스킬로 주는 피해"의 합) * (클래스별 스킬 대미지 증가 버프 관계)
```

### I. 방어력감소율 항

```text
I = 1 / (1 + 보스방어력 * (1 - 방어력감소/무시율%) / 10328)
```

* 보스 방어력 참고값

| 대상 | 방어력 |
|---|---|
| 허수아비 | 30 |
| 글라스기브넨 | 6410 |
| 화이트서큐버스 | 6410 |
| 어비스 지옥2 | 9153 |
| 바리어비스 | 15903 |

### J. 카운터 항

```text
J = 1.1
```

* 카운터 발생 시 최종 대미지 10% 증가

### K. 추가타 항
* 기대값 계산 시

```text
K = 1 + [ (1 + 추가타 / 13000) * (1 + 룬추확%) - 1 ] * (1 + 갈땅 추가대미지%) + (일렁, 천체 추가대미지%)
```

* 실제 대미지 계산 시

```text
K = 1
```

---

### L. 최종대미지증가

```text
L = (1 + 최종대미지증가%)
```

* 일체의 곱연산

#### 예시
- 장신구 초월 / 궁수 약점관통 / 댄서 템포


### 스킬계수 항

```text
스킬계수 = (0레벨 스킬계수) * (1 + 0.03 * 스킬레벨 + 0.02 * n)
```

#### n 증가 조건
* n은 0부터 시작하며 아래 조건 달성 시 1 증가
    - 스킬레벨 2 이상
    - 스킬레벨 10 이상
    - 스킬레벨 15 이상
    - 스킬레벨 20 이상
    - 스킬레벨 30 이상


### 클래스별 체크사항
#### 스킬 대미지 증가 판정

* 스킬 대미지 증가 버프툴팁, 특정 스킬만 강화하는 장신구/룬 등이 C항 피증인지 H항 스킬계수강화인지 직접 실험 필요

#### H항 / L항 분리 이유

* L항은 "최종대미지증가"
* H항은 특정 스킬 대미지 증가
* 엄밀히는 서로 다른 계열이므로 분류 유지
